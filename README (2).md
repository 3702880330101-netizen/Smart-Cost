# 📊 Smart-Cost: Modelo de Costos Industriales e Inteligencia Gerencial

Bienvenido a **Smart-Cost**, un sistema dinámico de análisis y modelado de costos industriales diseñado para la toma de decisiones estratégicas y la evaluación del impacto financiero en procesos de manufactura y producción.

---

## 🚀 Descripción del Proyecto

**Smart-Cost** permite a los gerentes de operaciones y administradores financieros simular, estructurar y analizar variables clave de producción en tiempo real. Mediante la integración de herramientas interactivas, la plataforma evalúa la sensibilidad de los costos, proyecta escenarios de optimización y calcula métricas clave como el Punto de Equilibrio y la Utilidad Operativa.

### ✨ Funcionalidades Principales

* **Entrada de Parámetros Dinámica:** Configuración de insumos (Materia Prima, MOD, Desperdicio, CIF, Costos Fijos, Volumen y Precio de Venta) con tooltips informativos y validación de campos.
* **Métricas en Tiempo Real:** Cálculo automático e inmediato de Costos Unitarios, Utilidad Total y Punto de Equilibrio en Quetzales ($Q$).
* **Gráfica de Sensibilidad Interactiva:** Visualización comparativa de escenarios mediante Chart.js para medir el impacto financiero ante fluctuaciones de costos.
* **Priorización y Optimización:** Tablas automatizadas que identifican las variables con mayor sensibilidad y proponen escenarios de mejora operativa.
* **Reporte Gerencial Automatizado:** Conclusiones estratégicas generadas a partir de los datos ingresados.
* **Exportación:** Capacidad de generación y descarga de informes en formato PDF.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 & JavaScript (ES6+):** Lógica del motor de cálculo e interacción con el usuario.
* **Tailwind CSS:** Framework de estilos para un diseño responsivo de dos columnas.
* **Chart.js:** Lógica para la visualización de datos y gráficos de barras comparativos.
* **Google Colab / Python:** Cuadernos de análisis exploratorio e integración con modelos analíticos.

## ⚙️ Instrucciones de Instalación y Uso

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/3702880330101-netizen/Smart-Cost.git
   ```
2. **Ejecutar la interfaz web:**
   * Abre el archivo `index.html` en cualquier navegador web moderno.
   * Modifica los valores de los parámetros en el panel izquierdo y observa cómo se actualizan automáticamente las métricas y la gráfica a la derecha.

3. **Ejecutar en Google Colab:**
   * Abre el cuaderno `SmartCost_AI.ipynb` directamente desde Colab para ejecutar las simulaciones y modelos analíticos.
